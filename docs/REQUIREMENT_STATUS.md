A category earns software-closure credit only when every original software subfeature is implemented across its required surfaces, has appropriate passing tests, and is merged. Partial subsets earn no **whole-category closure** credit. Category6.5 (truthful partner capability/availability restrictions) satisfies that narrow guardrail requirement; all other rows retain independently unfinished software. Thus category-closure coverage is **100×1/42 =2.38%**. This coarse binary metric is **not a feature-level estimate of the implemented platform**; it gives no partial credit for substantial working subsets. The previous informal70% baseline is not reused. A finer development percentage requires a complete agreed atomic-feature inventory and weights; no such estimate is asserted here. Production readiness is separate:0/42 categories are declared PRODUCTION_READY, and no hardware/merchant/partner/store acceptance is inferred.
