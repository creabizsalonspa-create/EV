# Weighted requirement coverage

Generated by `python3 scripts/requirement-coverage`. Inventory: `docs/evidence/requirements/inventory.json`.

Each original PRD category has weight1/42. Its explicitly named software atoms share that category weight equally. For each stage: `100 × sum(category stage-complete atoms / category total atoms) /42`. Stages are separate; they are never added together. Pending, failed, missing or wrong-source evidence earns no tested/merged credit. No credit is based on commits, lines or test counts.

A conservative, explicit software-coverage checklist, not production readiness, effort elapsed or commercial value. Equal category weights are a documented editorial choice. Missing or uncertain atoms receive no credit. No informal70% baseline is reused. Atom scope and required surfaces are stated; complete cross-platform parity remains separately uncredited where missing.
