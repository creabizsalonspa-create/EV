## Implemented scope

Customer/vendor Flutter can inspect the configured Open Charge Map source without a search, provider activation, location prompt or external tile request. An unavailable/unapproved source leaves managed/partner discovery available. Actual coordinates are submitted only after an explicit consent checkbox and Search action. One-time GPS reuses the existing foreground permission/service/fresh-fix reader; it only fills the draft, never searches automatically. Coordinates/search preferences are not persisted. Fields support radius, country, reported connector/operator/power, report age and explicitly reported membership/operating flags. Country/power/age inputs are validated and normalized before requests.

The typed response boundary accepts only bounded licensed crowd reports and consistent per-query quality samples. It checks source identity, per-record attribution/license, fixed original-source URL, finite geography/power, strict UTC source timestamps, reported-clock consistency, boolean types, duplicate IDs, connector capabilities and count evidence. Unexpected live availability, remote-control, booking, billing or full-coverage claims fail closed. Provider errors are generic and require an explicit retry; source search never auto-replays.

Results display reported connector/power, straight-line distance, age at search, unverified access/cost notes, attribution, license and bounded sample-quality counts in English/Arabic with RTL layouts and LTR numeric units. Literal provider text is never executed as HTML. Original-source links use a locally constructed fixed HTTPS URL. External driving navigation sends only the chosen destination to Google Maps after its labelled explicit button; no origin, account, booking or charging authority is included. Opening a navigation application is not verification of a road route or an operational charger.

The optional native map requires **separate OpenStreetMap tile consent** and displays only the already validated reports. It includes OSM attribution, permits local pan/zoom, and never performs background provider searches. Polar coordinates outside Web Mercator remain in the list. Query edits, refresh, GPS acquisition, backgrounding and identity changes drop old map/data authority. A fresh search requires a new map-enable action. A held response from an old account cannot leave old drafts, data or a spinner visible. Saved external-link callbacks recheck current account, generation and displayed source membership before launch.
